# CLI Commands

## Overview

```
spgtty [command] [flags]

Commands:
  build     Bundle JavaScript for Shelly (default command)
  upload    Upload script to Shelly device
  init      Create new Shelly script project
  help      Help about any command

Flags:
  -v, --version   Show version information
  -h, --help      Show help
```

---

## spgtty / spgtty build

Bundles JavaScript files for Shelly Gen2+ devices.

### Usage

```bash
# Build main.js (default)
spgtty

# Build specific file
spgtty myfile.js
spgtty build src/app.js

# Build without minification (for debugging)
spgtty -m
spgtty --notMinimize

# Specify output path
spgtty -o dist/output.js
```

### Flags

| Flag | Short | Description | Default |
|------|-------|-------------|---------|
| `--notMinimize` | `-m` | Disable minification | `false` |
| `--output` | `-o` | Output file path | `dist/main.js` |

### What it does

1. Reads the entry file (default: `main.js`)
2. Resolves all imports and bundles into single file
3. Transpiles to ES2015 (Shelly-compatible)
4. Minifies (unless `-m` flag)
5. Removes trailing commas (Shelly requirement)
6. Writes to output file (default: `dist/main.js`)

### Examples

```bash
# Simple build
$ spgtty
2025/05/20 10:00:00 ✅ Code nach dist/main.js geschrieben (1234 Bytes)

# Debug build (readable output)
$ spgtty -m test/main.js
2025/05/20 10:00:00 ✅ Code nach dist/main.js geschrieben (2456 Bytes)
```

## spgtty upload

Uploads a script to a Shelly Gen2+ device.

### Usage

```bash
# Upload using config file settings
spgtty upload

# Upload specific file
spgtty upload dist/main.js

# Specify host via flag
spgtty upload --host 192.168.1.100

# Specify script slot
spgtty upload --host 192.168.1.100 --script-id 2
```

### Flags

| Flag | Short | Description | Default |
|------|-------|-------------|---------|
| `--host` | `-H` | Shelly IP or hostname | (from config) |
| `--script-id` | | Script slot (1-10) | `1` |

### Configuration

The host can be set via:
- CLI flag: `--host 192.168.1.100`
- Environment: `SPGTTY_SHELLY_HOST=192.168.1.100`
- Config file: `shelly.host` in `.spgtty.yaml`

### What it does

1. Reads the script file (default: `dist/main.js`)
2. Connects to Shelly device via HTTP
3. Uploads in chunks (1024 bytes max per request)
4. Reports success/failure

### Examples

```bash
# Upload with host from config
$ spgtty upload
Uploading dist/main.js to 192.168.1.100 (script 1)...
✅ Upload successful!

# Upload to specific device
$ spgtty upload --host shelly-kitchen.local --script-id 3
Uploading dist/main.js to shelly-kitchen.local (script 3)...
✅ Upload successful!
```

## spgtty init

Creates a new Shelly script project with all necessary files.

### Usage

```bash
# Initialize in current directory
spgtty init

# Create new project directory
spgtty init my-shelly-project
```

### What it creates

```
my-shelly-project/
├── .spgtty.yaml    # Configuration file (edit with your Shelly IP)
├── main.js         # Entry point with Shelly boilerplate
├── src/            # Directory for modules
├── dist/           # Build output directory
└── .gitignore      # Ignores dist/ and optionally .spgtty.yaml
```

### Generated Files

**.spgtty.yaml**
```yaml
# spgtty configuration
shelly:
  host: ""           # IP or hostname of your Shelly device
  script_id: 1       # Script slot (1-10)

build:
  entry: "main.js"
  output: "dist/main.js"
  minify: true
```

**main.js**
```javascript
// Shelly Script - generated by spgtty
// Documentation: https://shelly-api-docs.shelly.cloud/gen2/Scripts/

function main() {
    print("Hello from Shelly!");
}

main();
```

### Example

```bash
$ spgtty init my-automation
✅ Project initialized in my-automation
Next steps:
  1. Edit .spgtty.yaml and set your Shelly IP
  2. Write your code in main.js
  3. Run 'spgtty build' to compile
  4. Run 'spgtty upload' to deploy
```

## Common Workflows

### Development Workflow

```bash
# 1. Create project
spgtty init my-project
cd my-project

# 2. Configure Shelly IP
# Edit .spgtty.yaml, set shelly.host

# 3. Write code
# Edit main.js

# 4. Build and test locally
spgtty -m  # No minification for debugging

# 5. Build for production
spgtty

# 6. Deploy
spgtty upload
```

### Quick Test

```bash
# One-liner to build and upload
spgtty && spgtty upload --host 192.168.1.100
```

### CI/CD Integration

```bash
# In GitHub Actions or similar
export SPGTTY_SHELLY_HOST="${{ secrets.SHELLY_IP }}"
spgtty build
spgtty upload
```
